# Open-Source 3D Printer Project

An accessible, modular, and customizable 3D printer design built for makers, students, and independent engineers. This repository provides mechanical models, firmware configurations, and calibration guides to simplify assembly and improve print reliability.

## Features
- Modular Frame & Mechanical Parts: Easy-to-source components and printable upgrades.
- Firmware & Control: Optimized configuration profiles for smooth motion and thermal stability.
- Calibration Suite: Step-by-step guides for bed leveling, extrusion tuning, and dimensional accuracy.

## Repository Structure
- /cad — 3D models and STL files for custom printed parts.
- /firmware — Configuration files and control scripts.
- /docs — Assembly instructions and troubleshooting notes.
